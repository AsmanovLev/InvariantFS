Linux · Bit-Exact Filesystem

InvariantFS

Semantic, content-addressed filesystem engineered for verified storage invariants, zero hidden bit rot, and instant dual-device rootfs boots.

$curl -fsSL https://invfs.ru/sh | sh
Core Principles

Bit-Exactness Invariant

Every stored block undergoes an immediate decompress-and-compare verification roundtrip before publish. Silent bit corruption is mathematically rejected.

Semantic Deduplication

Multi-level recipe trees (CHLD) with container awareness (ISO, WIM, TAR, ZIP) eliminate duplicate payloads across independent workloads.

Native Linux Rootfs Boot

Runs as PID 1 root mount with first-class support for Arch Linux, Debian/Ubuntu, Gentoo, and Void via custom initramfs hooks.

Dual-Tier Storage

Ultra-low latency NVMe/SSD raw write path paired with durable mechanical shadow backing and offline reference-counting sweep.
