InvariantFS

Semantic, content-addressed filesystem engineered for verified storage invariants, zero silent corruption, and instant dual-device rootfs boots.

$curl -fsSL https://invfs.ru/sh | sh
System Architecture

01 / Bit-Exact Invariant

Every stored block undergoes an immediate decompress-and-compare verification roundtrip before commit. Corrupted payloads cannot be published.

02 / Semantic Deduplication

Multi-level recipe trees (CHLD) and container unpacking (ISO, WIM, TAR, ZIP) eliminate duplicate payloads across independent workloads.

03 / Dual-Tier Storage & Sweep

Fast SSD raw zone handles live synchronous writes, backed by immutable HDD shadow storage with offline reference-counting compaction (sweep).

04 / Native Rootfs Boot

Runs directly as PID 1 root mount with first-class support for Arch Linux, Debian/Ubuntu, Gentoo, and Void via custom initramfs hooks.
