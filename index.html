InvariantFS

Семантическая файловая система с инвариантом побитовой точности, защитой данных decompress-and-compare и поддержкой загрузки Linux rootfs.

curl -fsSL https://invfs.ru/sh | sh
GitHub Репозиторий Релизы Матрица установки

🛡️ Bit-Exactness Invariant

Каждое сжатие верифицируется циклом разжатия и побайтового сравнения перед фиксацией. Никаких скрытых повреждений данных.

🚀 Native Distro Packaging

Автоматическая установка нативных пакетов для Arch Linux (.pkg.tar.zst), Debian/Ubuntu (.deb), Fedora/RHEL (.rpm), Gentoo и Void Linux.

🐧 Rootfs Boot Support

Полная интеграция с mkinitcpio, dracut и initramfs-tools. Возможность загрузить систему с InvariantFS в качестве корня (/dev/sda).

📦 Content-Addressed De-dupe

Многоуровневые деревья рецептов CHLD, потоковые контейнеры (ISO9660, WIM, TAR, ZIP) и авто-дедупликация идентичных блоков.
